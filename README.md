Business Rules
Cakes require a minimum of 24 hours' advance notice.
Standard food delivery target is within 3 hours.
Delivery is available only within a 20 km radius of Lakkur.
Show a serviceability checker based on pincode and GPS.
Generate default prices suitable for the Malur market; allow the admin to edit all prices later.
Use premium AI-generated food images as placeholders until real photos are uploaded.
Display "Out of Stock" automatically when inventory reaches zero.
Allow scheduled deliveries and pre-orders.
No refunds once an order has been confirmed.
